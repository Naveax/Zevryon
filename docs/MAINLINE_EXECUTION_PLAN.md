# MassiveDoc Mainline Execution Plan

## Rule zero

No optimization is accepted if it reduces document correctness. Full selection, copy, search, export, source-byte fidelity and semantic order are invariants.

## M1 — Native segmented source and bounded process control

The native source store and bounded process-control work are implemented as described by the admitted repository history. Remaining browser logical-node compaction continues independently where still applicable.

## M2 — Compact logical arena and chunked order-statistics sequence

Continue replacing remaining document-order/vector hot paths with compact bounded structures, preserving O(log n) mutation/access and snapshot correctness.

## M3 — Crash-safe segmented generations and mobile I/O

The segmented source store, generation protocol, compaction, quarantine, positional I/O and 32-bit address-space gates are admitted through the existing exact-head CI history.

## M4 — Bounded search and full-document operations

Disk-backed bounded search, Unicode normalization, exact matching, cancellation, selection and streaming export remain correctness authorities.

## M5 — Frame-budget scheduler

Device-profile frame budgets, foreground layout handoff, bounded prefetch and pressure-aware scheduling remain required performance authorities.

## M6 — Cross-platform low-memory backend

Windows, Linux, Android contract surfaces and 32-bit file-position/address-space gates remain required. Apple platforms remain intentionally unsupported under the current target policy.

## M7 — Competitor laboratory

M7 implementation/admission is frozen through the v2 raw-artifact replay and artifact-root-containment authority. Real six-runtime physical-host collection, Zevryon physical cases, v2 admission, five-metric evaluation and publication remain physical evidence work and must not be fabricated from CI.

One leadership decision consumes one complete evidence bundle. Repeats may be collected as independent reproducibility evidence, but best-of-N reruns and cross-bundle metric mixing are not admissible. Any repeated-run aggregation policy must be frozen before collecting the evidence it would aggregate.

Final M8 certification remains no-compensation: every required axis must independently pass from raw evidence.
